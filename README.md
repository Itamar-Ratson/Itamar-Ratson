## Featured Project

### [Zero-Trust Hybrid-Cloud DevSecOps Platform](https://github.com/Itamar-Ratson/devsecops)

End-to-end DevSecOps platform on Kubernetes with zero-trust networking, GitOps delivery, and full observability. Deploys a KinD cluster with Cilium CNI, extends to AWS EKS via Cluster Mesh, and automates everything through Terraform/Terragrunt and ArgoCD.
